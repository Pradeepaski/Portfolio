# Personal Portfolio Website

A clean, modern, and responsive personal portfolio website built for Pradeep S Aski, a Computer Science Engineering student at RNS Institute of Technology.

## 🚀 Features

- **Fully Responsive**: Adapts perfectly to desktop, tablet, and mobile screens.
- **Modern UI/UX**: Clean design with smooth scrolling, hover animations, and a polished aesthetic.
- **Dynamic Projects Section**: Showcases Machine Learning and Computer Vision projects.
- **Functional Contact Form**: Integrated with [FormSubmit](https://formsubmit.co) for easy email delivery without a back-end server.
- **No Frameworks**: Built using pure HTML5, CSS3, and Vanilla JavaScript.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and layout structure.
- **CSS3**: Custom styling, Flexbox/Grid layouts, and animations.
- **JavaScript (ES6+)**: Smooth scrolling and Intersection Observer API for scroll animations.

## 📂 Project Structure

```
├── index.html     # Main HTML document
├── style.css      # Custom stylesheet
├── script.js      # Interactive features and animations
└── images/        # Directory for profile and project images (add your images here)
```

## 💻 How to Run Locally

You don't need any special tools to run this project!

1. Clone or download this repository.
2. Open the folder containing the project files.
3. Simply double-click on `index.html` to open it in your default web browser.
   - *Alternatively, drag and drop `index.html` into an open browser tab.*

### For Live Editing (Recommended):
If you want to edit the code and run a local development server:
1. Open the project folder in **Visual Studio Code**.
2. Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension.
3. Right-click on `index.html` and select **"Open with Live Server"**.

## 🖋️ Customization

- **Profile Picture**: Place an image named `profile.jpg` inside the `images/` directory to automatically update the hero section.
- **Project Images**: Add screenshots of your projects to the `images/` folder and update the `<div>` placeholders in `index.html` with an `<img>` tag or CSS `background-image`.

## 📬 Contact Form Setup

The contact form is pre-configured to send emails to the provided email address using **FormSubmit**. 
**Important Requirement:** To activate it, simply submit one test message through the form and click the activation link that will be sent to your college inbox.
